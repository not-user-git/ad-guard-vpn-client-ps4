# AdGuard VPN Client for PS4

Неофициальный Homebrew-клиент для PlayStation 4 с GoldHEN, предназначенный для подключения к коммерческой инфраструктуре AdGuard VPN.

## Основная идея

Маршрутизация игрового трафика через VPN с сохранением прямого подключения для системного трафика PS4.

## Возможности

- Подключение к AdGuard VPN.
- Выбор VPN-сервера и локации.
- Маршрутизация трафика выбранных игр (*Selected Games Only*).
- Kill Switch для защиты игрового трафика.
- Управление подключением и настройками.
- Диагностика VPN-соединения.

## Технологии

- C / C++ — системная логика и приложение.
- SDL2 — пользовательский интерфейс.
- GoldHEN — интеграция с PS4.
- IPsec / IKEv2 — основной исследуемый вариант VPN-протокола.
- OpenOrbis PS4 Toolchain — разработка и сборка.

*Технологический стек предварительный. Совместимость компонентов с Orbis OS требует проверки.*

## Ограничения

Проект не является официальным продуктом AdGuard. Возможность реализации полноценной маршрутизации игрового трафика зависит от доступных механизмов сетевого перехвата и ограничений PS4.

## Цель

Создать стабильное нативное Homebrew-приложение для PS4, обеспечивающее выборочную маршрутизацию игрового трафика через AdGuard VPN.
